## 真实 PG 计费验收细节

计费 HTTP 用例使用 `OPERATIONS_TEST_DATABASE_URL` 所指测试库，每个用例创建独立随机 schema，Store 与 operations 通过同一 search_path 访问该 schema，结束时清理；没有连接生产库执行写入。

- 实际 token 用量成本大于预扣、余额不足覆盖最终成本时，生成图片仍保留，结算形成负余额；成功任务没有退款。下一任务在调用上游前被阻止。
- 上游响应没有 usage 时，保留单位价格扣费，未按零成本处理。
- 相同 `_jobTaskRef` 已有 ready 收据时，恢复结算与后续 settled 重放均复用已有结果，不重复请求模型。
- 普通用户页额度走真实 `usage_daily` 事务预留；成功记用量，额度超限返回 HTTP 429 并补偿预扣。生成失败时释放页额度并退回预扣。
- 注册默认关闭；启用邀请策略后，缺失或错误邀请码返回 403，正确邀请码注册成功并设置会话 Cookie。

## 已知边界与未覆盖项

1. **上游响应至 durable stage 的崩溃窗口仍存在。** 上游已完成但应用尚未持久化 ready 收据时若进程崩溃，重试可能再次调用上游。ready/settled 的恢复去重验证不覆盖该窗口，也不构成上游端 exactly-once 保证。需要核对任务、产物和账本，必要时结合提供商幂等键或任务查询处理。
2. **限流与调度面向单进程。** 每用户分钟窗口、并发限制以及本地队列状态属于单服务实例；PG 日额度的事务保护不等于多副本全局限流。多副本共享 data/queue 的部署未支持，不把当前实例直接横向扩容。
3. **S3/WebDAV 使用 httptest 协议回归。** 尚未以真实云账号验证供应商 endpoint、桶权限、签名兼容性、网络、生命周期、费用和恢复。通过协议测试不等于云存储生产可用验收。
4. **宝塔/systemd/nginx 以配置资产交付。** 尚未在真实宝塔站点完成安装、证书、守护、SSE 和上传链路验收。隔离 Docker 的 HTTP 探测不替代此环境实测。
5. **没有付费模型真图调用。** 生成链路测试使用本地假响应；真实模型质量、提供商限额、价格、超时和异常协议需另行验证。提示词要求简体中文不保证图片内中文字形或排版正确；字形质量需真实样图人工检查。
6. **PG16 实测与 PG17 模板分开记录。** Linux 实测使用 PG16；Compose 使用 PG17。部署前还需在 PG17 完成 schema、备份恢复及相关集成测试。
7. **副本验证不是生产切换。** 13 项目和当前项目图片检查仅证明该副本及所列数据路径，未声明所有历史项目、支付网关、真实模型和生产迁移全部验收完成。源库、原始目录与回切快照应继续保留。
8. **失败补偿仍需监控。** 数据库不可达或进程被强制终止时，页额度预留和计费中间态可能需要恢复与对账；进程内 defer 不覆盖机器故障。备份脚本与恢复教程的存在不代表每个目标部署均已完成恢复演练。
